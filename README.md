Quevra 🎓

Learn without limits.

Quevra is an AI-powered learning platform built to help Nigerian secondary school students learn, understand difficult topics, and improve their academic performance.

Designed around the Nigerian secondary school curriculum, Quevra provides students with an interactive learning experience supported by AI-powered educational tools.

🌐 Live Website: https://quevra.zevcloud.app

✨ Features

AI Tutoring: Get explanations and assistance with academic topics.

Interactive Learning: Explore subjects and topics through structured learning content.

Ask AI: Ask questions and get AI-generated educational responses.

Assignment Assistance: Upload assignments for AI-assisted academic support.

Student Dashboard: Access learning activities and important study information.

Multiple Subjects: Supports different subjects across Nigerian secondary school levels.
